# 🌸 Flowers Website 🌸  

A simple and elegant webpage showcasing different flowers, their meanings, and symbolic significance.  

## 🌟 Features  
- 🎨 **Beautiful Design** – Dark theme with crimson highlights.  
- 🌺 **Flower Cards** – Displays images, descriptions, and "Read More" links.  
- 📱 **Responsive Layout** – Works on different screen sizes.  
- 📩 **Newsletter Subscription** – Users can subscribe via email.  
- ⚡ **Built With** – HTML, CSS, and JavaScript.
